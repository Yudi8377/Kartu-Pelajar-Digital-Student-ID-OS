# Hatchable-port: Student ID OS card designer prototype

This is a framework-free HTML/CSS/JavaScript UI prototype intended for a manual Hatchable compatibility experiment. It contains synthetic demo values only.

## Run locally
Open `index.html` in a modern browser. No build step, framework, external dependency, database, or login is required.

## Included
- Editable school name/code and sample student fields
- Live card theme preview
- Composite display-label preview (not a canonical identity or credential)
- Clear indication that QR issuance and backend are not available
- Attendance method planning and device-limit notes

## Not included
- Authentication, authorization, persistence, Neon connectivity, QR/barcode generation, real attendance, GPS, BLE, or student tracking.
- This prototype must not be used with real student data.
- Do not import the root Next.js repository as a Hatchable project. Test only these four files in a separate Hatchable project, after reviewing the current platform terms and privacy controls.
